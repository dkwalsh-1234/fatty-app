Halo · pine and lime

Lime is a light, high-chroma colour, so it only ever sits on deep pine. In light mode the ring lives on a pine hero band and every primary button touches pine: a lime button inside the pine dock, or a pine button with a lime label on cream. The rest of the page is sage with cream cards and deep pine text, never black on white. Each macro colour has two tunings of the same hue: a soft pastel for pine surfaces and a deeper tone for cream ones, so both read at the same strength.
